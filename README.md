# Dalia's Kitchen - Website Guide

Your website is fully developed and ready to run! Here is everything you need to know.

## 📂 Project Structure
- `index.html` → The main website for your customers.
- `admin.html` → The control panel for you to manage products and settings.
- `style.css` → Contains all the premium design styles.
- `script.js` → The brain of the website (logic).
- `admin.js` → The logic for the admin panel.
- `products.js` → Stores your initial product data.
- `invoice.js` → Handles printing receipts.

## 🚀 How to Run (Offline / Locally)
Since this site uses pure HTML/JS, you don't need to install any complex software.
1.  Open the folder containing these files.
2.  Double-click `index.html` to open the **Customer Website**.
3.  Double-click `admin.html` to open the **Admin Panel**.

**Note**: Your data (Products, Visitors, Settings) is saved in your **Browser's Local Storage**. If you open the site on a different computer or clear your history, the data will reset to defaults.

## 🌐 How to Deploy (Online)
To put this website on the internet for everyone to see via a link (e.g., `daliakitchen.com`), you can use free hosting services for static sites.

### Option 1: Netlify Drop (Easiest)
1.  Go to [Netlify Drop](https://app.netlify.com/drop).
2.  Drag and drop your entire project folder into the box.
3.  It will instantly give you a link to share!

### Option 2: Github Pages
1.  Upload your files to a GitHub repository.
2.  Go to Settings -> Pages -> Enable GitHub Pages.
